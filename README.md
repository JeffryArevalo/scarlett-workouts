# Scarlett's Workouts

A small web app that shows the week's strength workouts, one day per button. Tap an exercise to see sets, reps, and a photo of how to do it.

- Hosted on GitHub Pages. Open it in Safari on iPhone, tap Share, then "Add to Home Screen" to use it like an app.
- To change a workout, edit `data.js`. To add a missing photo, drop a JPG in `images/` and set its name in `data.js`.
