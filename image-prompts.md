# Image prompts for Scarlett's Workouts

One prompt per exercise. Generate in Google Flow, save the result as the filename shown, and drop it into `workout-app/images/`. Landscape 4:3 fits the app best.

Every prompt uses the same subject and setting so the set looks consistent:
"a fit athletic woman in her 30s, hair in a ponytail, black sports bra and dark grey leggings, in a bright modern commercial gym".
